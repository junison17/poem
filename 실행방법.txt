이 프로그램을 실행하는 방법은 다음과 같습니다:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

방법 1: 간단한 실행 (추천)
   1. "start_app.bat" 파일을 더블클릭합니다
   2. 브라우저가 자동으로 열립니다
   3. 끝!

방법 2: 수동 실행
   1. 명령 프롬프트(cmd)를 엽니다
   2. 이 폴더로 이동합니다
   3. 다음 명령어를 입력합니다:
      streamlit run app.py
   4. 브라우저에서 http://localhost:8501 을 엽니다

   ./start_app.sh

방법 2: 수동 실행
   터미널에서 다음 명령어를 실행합니다:
   streamlit run app.py

1. Python 3.8 이상이 설치되어 있어야 합니다

   - .streamlit/secrets.toml 파일로 만들고
   - 실제 API 키를 입력하세요

Q: 왜 exe 파일이 아닌가요?
A: Streamlit 웹 애플리케이션은 브라우저에서 실행되는 특성상,
   단일 exe 파일로 변환하는 것이 매우 복잡하고 불안정합니다.
   대신 배치 파일(.bat)을 사용하면 더 간단하고 안정적으로 실행할 수 있습니다.

Q: 프로그램을 종료하려면?
A: 명령 프롬프트 창을 닫거나 Ctrl+C를 누르세요.

Q: 다른 포트를 사용하고 싶어요
A: start_app.bat 파일을 수정하여 8501을 다른 번호로 변경하세요.
