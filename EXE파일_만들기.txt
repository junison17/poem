================================================================================
           🔧 Windows용 EXE 파일 만드는 방법
================================================================================

⚠️ 중요: EXE 파일은 반드시 Windows 컴퓨터에서 만들어야 합니다!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 방법 1: 자동 빌드 (가장 쉬움!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Windows 컴퓨터에서 이 폴더를 엽니다
2. "build_exe.bat" 파일을 더블클릭합니다
3. 완료될 때까지 기다립니다 (1-2분 소요)
4. "dist" 폴더에서 "시와그림생성기.exe" 파일을 찾습니다!

📁 생성된 EXE 파일 위치:
   이 폴더\dist\시와그림생성기.exe

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 방법 2: 수동 빌드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

명령 프롬프트(cmd)를 열고 다음 명령어를 차례대로 실행:

1. PyInstaller 설치:
   pip install pyinstaller

2. EXE 빌드:
   pyinstaller --clean --onefile --name "시와그림생성기" --add-data "app.py;." --add-data ".streamlit;.streamlit" --console launcher.py

3. 완료!
   dist 폴더에서 "시와그림생성기.exe" 찾기

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 참고사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ EXE 파일 크기: 약 10-50MB (정상입니다)
✅ 빌드 시간: 1-2분 정도 소요
✅ 필요한 것: Python 3.8 이상이 설치된 Windows PC

⚠️ 주의사항:
   - Linux나 Mac에서는 .exe가 아닌 다른 형식의 실행 파일이 생성됩니다
   - Windows에서만 .exe 파일을 만들 수 있습니다
   - 백신 프로그램이 실행을 차단할 수 있습니다 (정상입니다)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 EXE 없이 바로 실행하기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXE 파일을 만들지 않아도 됩니다!
"start_app.bat" 파일을 더블클릭하면 바로 실행됩니다.
(EXE 파일처럼 간편하게 사용 가능)
